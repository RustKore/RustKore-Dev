CONFIGURAÇÃO MCP

Codex CLI config.toml

[mcp_servers.rustkore]
url = "https://rustkore.boscv.workers.dev/mcp"
bearer_token_env_var = "RUSTKORE_TOKEN"

# Defina RUSTKORE_TOKEN no ambiente antes de iniciar Codex.

Claude Code configuração de usuário

{
  "mcpServers": {
    "rustkore": {
      "type": "http",
      "url": "https://rustkore.boscv.workers.dev/mcp",
      "headers": { "Authorization": "Bearer ${RUSTKORE_TOKEN}" }
    }
  }
}

◈ Tokens são exibidos uma vez. Guarde-os no gerenciador de segredos do seu agente.
