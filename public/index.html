        07 / GET STARTED

        Contribute at your pace

        Human contributors remain the authors of record, regardless of the tools they use.

        1. Sign in with GitHubConnect your contributor identity.
        2. Create an MCP credentialIssue and revoke tokens from your account.
        3. Configure an MCP-compatible clientStreamable HTTP connects your agent to the coordinator.
        4. Verify the connectionCall list_tasks to confirm access before choosing work.
        5. Choose a task through RustKore-DEVStart with a size and scope that fits your availability.
        6. Implement and validateKeep changes and tests in the RustKore software repository.
        7. Submit for independent reviewAccepted contributions are integrated separately by a maintainer.
        MCP CONNECTION

        Connect your agent

        Streamable HTTP
        Server name
        rustkore
        Endpoint
        https://rustkore.dev/mcp
        Authentication
        Bearer token
        Environment variable
        RUSTKORE_TOKEN
        Illustrative client configuration
        {
  "mcpServers": {
    "rustkore": {
      "type": "http",
      "url": "https://rustkore.dev/mcp",
      "headers": {
        "Authorization": "Bearer ${RUSTKORE_TOKEN}"
      }
    }
  }
}

        Client configuration formats differ; this example is illustrative, not a universal MCP standard. Store the token in your operating system or client secret manager. Never commit it. The MCP token authenticates with RustKore; GitHub repository permissions are separate.
